# FPGA-classd

Экспериментальный цифровой модулятор class-D на ПЛИС Gowin GW5A для усилителя DigiD D1 — параллельная ветка к AX5689.

- Выходные каскады: ISG3208 (GaN), полный мост (BTL) на канал.
- Модуляция: BD (трёхуровневая), несущая 768 кГц (49,152 МГц / 64), обновление 1,536 МГц = 8 × 192 кГц.
- Фронты на сетке OSER ×16: шаг 1,27 нс, 512 тиков на полупериод.
- План: сначала open-loop, затем глобальная ООС после LC-фильтра.

## Структура

```
model/classd_model.py   модель тракта: интерполяция, шейпер, BD-ШИМ, LC + нагрузка,
                        dead time (с учётом ZVS), джиттер, пульсации шины, анализ THD+N
model/run_openloop.py   прогон сценариев -> results/
results/summary.md      таблица результатов
results/*.png           спектры
```

Запуск:

```
pip install -r requirements.txt
python model/run_openloop.py
```

Один прогон в коде:

```python
from classd_model import Params, run, db
r = run(Params(deadtime=5e-9, r_load=4.0))
print(db(r["thdn"]), db(r["thd"]))
```

## Как устроена модель

1. PCM 192 кГц → интерполяция ×8 → 1,536 МГц.
2. Опционально feedforward: деление на измеренное напряжение шины.
3. Шейпер с обратной связью по ошибке. NTF 5-го порядка с оптимизированными нулями, OBG 3.
4. BD-разбиение уровня между плечами, центрированный двухфронтовый ШИМ.
5. Ток дросселей в моменты фронтов из точной модели LC + нагрузка + Zobel (кусочно-постоянный вход, матричная экспонента).
6. Сдвиг каждого фронта:
   - dead time: жёсткое переключение, полный или частичный ZVS по Coss и току;
   - белый джиттер.
7. Дифференциальное напряжение моста выбирается точным треугольным ядром на 24,576 МГц, затем децимация до 192 кГц и когерентный FFT.

LC-фильтр линейный, поэтому спектр в звуковой полосе на выходе моста совпадает со спектром на динамике с точностью до АЧХ фильтра.

## Результаты open-loop (1 кГц, −1 дБFS, 8 Ом, если не указано)

Полная таблица: [results/summary.md](results/summary.md).

| Сценарий | THD+N, дБ |
|---|---:|
| Идеальный тракт, 1 кГц | −118 |
| Идеальный тракт, 6,6 кГц | −85 |
| BD-разбиение с шагом 1 тик (parity) | −108 |
| Джиттер 10 / 50 / 100 пс RMS | −105 / −91 / −85 |
| Dead time 2 / 5 / 10 нс | −78 / −61 / −47 |
| Dead time 5 нс, 4 Ом | −56 |
| Dead time 5 нс, без нагрузки | −111 |
| Пульсации шины 1 % / 100 Гц без feedforward / с ним | −43 / −118 |

### Выводы

1. **BD-разбиение: только чётные шаги.** Если дифференциальный уровень квантовать с шагом 1 тик, сумма тиков плеч чередуется (nh / nh+1). Центр импульса тогда смещается на ½ тика вместе с чётностью шума квантования, и появляется пропорциональный сигналу шум около −108 дБ. С шагом 2 тика синфазный уровень постоянен, и шума нет. Шейперу это ничего не стоит: 513 уровней хватает с запасом. См. `results/bd_split.png`.
2. **Нелинейность UPWM растёт с частотой.** На 1 кГц −118 дБ, на 6,6 кГц уже −85 дБ. До closed-loop нужна коррекция ШИМ (предыскажение или пересчёт точки пересечения).
3. **Джиттер.** Чтобы быть ниже −100 дБ, нужно около 10 пс RMS на фронтах. Вероятно, понадобится переклокировать выходы внешними триггерами от чистого 49,152 МГц, а не брать фронты прямо с PLL.
4. **Dead time — главный враг open-loop.** Пока ток нагрузки меньше половины размаха пульсаций, фронты идут с ZVS, и искажения мизерные. Без нагрузки и на −20 дБFS это −111 / −142 дБ. На полной мощности 8 / 4 Ом фронты переходят в жёсткое переключение: −61 / −56 дБ при 5 нс. Варианты:
   - минимальный dead time;
   - компенсация по знаку прогнозируемого тока;
   - closed-loop.
   
   Более низкая несущая даёт больший размах пульсаций и расширяет зону ZVS.
5. **Пульсации шины** полностью убираются feedforward (в модели измерение идеальное).

### Допущения, которые нужно уточнить

- Dead time ISG3208 и эквивалентная Coss: в модели 2–10 нс и 250 пФ, нужно сверить с даташитом.
- DCR дросселя 10 мОм.
- Джиттер белый и независимый по фронтам.
- Шина 50 В.
