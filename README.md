# FPGA-classd

Экспериментальный цифровой модулятор class-D на ПЛИС Gowin GW5A для усилителя DigiD D1 — параллельная ветка к AX5689.

- Выходные каскады: ISG3208 (GaN), полный мост (BTL) на канал.
- Модуляция: BD (трёхуровневая), несущая 768 кГц (49,152 МГц / 64), обновление 1,536 МГц = 8 × 192 кГц.
- Фронты на сетке OSER ×16: шаг 1,27 нс, 512 тиков на полупериод.
- План: сначала open-loop, затем глобальная ООС после LC-фильтра.

## Структура

```
model/classd_model.py   модель тракта: интерполяция, шейпер, BD-ШИМ, LC + нагрузка,
                        dead time (с учётом ZVS), джиттер, пульсации шины, анализ THD+N
model/run_openloop.py   прогон сценариев -> results/
results/summary.md      таблица результатов
results/*.png           спектры
```

Запуск:

```
pip install -r requirements.txt
python model/run_openloop.py
```

Один прогон в коде:

```python
from classd_model import Params, run, db
r = run(Params(deadtime=5e-9, r_load=4.0))
print(db(r["thdn"]), db(r["thd"]))
```

## Как устроена модель

1. PCM 192 кГц → интерполяция ×8 → 1,536 МГц.
2. Опционально feedforward: деление на измеренное напряжение шины.
3. Коррекция UPWM m = x − D²(x³)/24.
4. Шейпер с обратной связью по ошибке. NTF 5-го порядка с оптимизированными нулями, OBG 3.
5. BD-разбиение уровня между плечами, центрированный двухфронтовый ШИМ.
6. Ток дросселей в моменты фронтов из точной модели LC + нагрузка + Zobel (кусочно-постоянный вход, матричная экспонента).
7. Сдвиг каждого фронта:
   - dead time: жёсткое переключение, полный или частичный ZVS по Coss и току;
   - белый джиттер.
8. Дифференциальное напряжение моста выбирается точным треугольным ядром на 24,576 МГц, затем децимация до 192 кГц и когерентный FFT.

LC-фильтр линейный, поэтому спектр в звуковой полосе на выходе моста совпадает со спектром на динамике с точностью до АЧХ фильтра.

### Выводы

1. **BD-разбиение: только чётные шаги.** Если дифференциальный уровень квантовать с шагом 1 тик, сумма тиков плеч чередуется (nh / nh+1). Центр импульса тогда смещается на ½ тика вместе с чётностью шума квантования, и появляется пропорциональный сигналу шум около −108 дБ. С шагом 2 тика синфазный уровень постоянен, и шума нет. Шейперу это ничего не стоит: 513 уровней хватает с запасом. См. `results/bd_split.png`.
2. **Нелинейность UPWM снимается одной строчкой.** Без коррекции она растёт с частотой: −118 дБ на 1 кГц, −85 дБ на 6,6 кГц, IMD 18+19 кГц −94 дБ. При разбиении с постоянным CM каждый полупериод несёт один дифференциальный импульс ширины w с **фиксированным** центром. Его спектр на низких частотах равен w − ω²w³/24 + …, то есть тракт добавляет к последовательности отсчётов D²(w³)/24. Обратная коррекция до шейпера:

   ```
   m[k] = x[k] − (x[k−1]³ − 2·x[k]³ + x[k+1]³) / 24
   ```

   В ПЛИС это куб, вторая разность и сдвиг со сложением. Результат: −147 дБ на 6,6 кГц и IMD −150 дБ. Нелинейность UPWM больше не ограничивает. См. `results/pwm_corr.png`.
3. **Джиттер.** Чтобы быть ниже −100 дБ, нужно около 10 пс RMS на фронтах. Вероятно, понадобится переклокировать выходы внешними триггерами от чистого 49,152 МГц, а не брать фронты прямо с PLL.
4. **Dead time — главный враг open-loop, и его надо держать в 1–2 нс.** У ISG3208 Coss(TR) 805 пФ, поэтому за 1–5 нс узел почти не успевает сдвинуться током пульсаций (полный ZVS-переход занял бы около 47 нс). Ошибка фронта тогда почти одинаковая при любом знаке тока, а искажения растут примерно как квадрат dead time: 1 нс — −100 дБ, 2 нс — −88 дБ, 5 нс — −72 дБ на 8 Ом. Без нагрузки и на малых уровнях всё ниже −139 дБ. ISG3208 это позволяет: входы PWMH/PWML раздельные, есть встроенная блокировка и адаптивная защита от сквозного тока со своим dead time около 1 нс. Значит, dead time задаём в ПЛИС с шагом 1,27 нс, начиная с 1–2 тиков, и подбираем на стенде.
5. **Пульсации шины** полностью убираются feedforward (в модели измерение идеальное).

### ISG3208: что учтено и что важно для ПЛИС

Из даташита ISG3208EA Rev 1.0:

| Параметр | Значение | Что это значит для модулятора |
|---|---|---|
| Входы | раздельные PWMH / PWML, TTL (VIH ≤ 2,2 В), до 5,5 В | dead time формирует ПЛИС; LVCMOS 3,3 В подходит |
| Блокировка | H+L одновременно → оба ключа выключены, адаптивная защита, свой dead time ≈ 1 нс | можно работать с dead time 1–2 тика |
| Coss(TR) / Qoss | 805 пФ / 40 нК при 0–50 В | заложено в модель |
| Задержка | 20 нс, согласование H/L ±1 нс | рассогласование ведёт себя как dead time; между мостами — постоянный сдвиг плеч |
| Мин. входной импульс | 10 нс (антидребезг), выход растягивается до 12 нс | ограничитель модуляции в ПЛИС: импульсы и паузы не короче ~12–15 нс, это около 97–98 % модуляции |
| Фронты затвора | включение 10 нс, выключение 3 нс | эффективный dead time чуть больше заданного |

### Допущения модели

- DCR дросселя 10 мОм.
- Джиттер белый и независимый по фронтам.
- Шина 50 В.
- Не моделируется зависимость самого жёсткого переключения (dv/dt) от тока нагрузки. При dead time 1–2 нс именно она станет следующим источником искажений, и её закроет closed-loop.
