# Open-loop: результаты модели

Несущая 768 кГц (BD), обновление 1.536 МГц, шаг фронта 1.272 нс (512 тиков на полупериод), NTF 5-го порядка, OBG 3.0. Шина 50 В, L 4.7 мкГн, C на землю 470 нФ, C дифф. 470 нФ, Zobel 4.7 Ом + 470 нФ, Coss 805 пФ. Сигнал −1 дБFS, 1 кГц, если не указано иное. Полоса 20 Гц–20 кГц.

Для двухтонового сигнала колонка THD — это IMD (2f1−f2, 2f2−f1, f2−f1).
