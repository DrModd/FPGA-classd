# Номиналы АЦП обратной связи (AP2 + реплика ×8 + sinc2)

Шина 50 В, опора 3.3 В (LDO), такт 49.152 МГц, τ2 = 0.5 мкс. Значения на одну сторону дифференциальной схемы (всё ×2, кроме C2).

| Элемент | Номинал | Назначение |
|---|---:|---|
| Rin | 47 кОм | вход с ноги моста, E192, 0,1 %, 0,25 Вт |
| Rrep | 3.09 кОм | от буфера реплики; Rin/Rrep задаёт усиление |
| Rdac1 | 24.9 кОм | ЦАП 1-го интегратора; шкала АЦП = Vшины/8 |
| Rcm | 1.33 кОм | к земле, синфазный ток, Vicm ≈ 1 В |
| C1 | 18 пФ | C0G, ОС интегратора, ×2 |
| R2 | 1 кОм | выход ОУ → 2-й интегратор |
| C2 | 270 пФ | C0G, плавающий между N2+ и N2− |
| Rdac2 | 11.5 кОм | ЦАП 2-го интегратора |
| Rs | 100 Ом | N2 → вход компаратора |
| Rk0 | 100 кОм | компенсация ELD |

Реализованные коэффициенты: a1 = 0.299 (цель 0.298), a2 = 0.639 (0.643), k0 = 0.175 (0.178), τ2 = 0.49 мкс, G = 8.03, разбаланс реплики -0.10 %, масштаб на входе компаратора 18.8 мВ/ед.
